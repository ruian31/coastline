# 逐海 · Golden Coast

一款以海岸风景、敞篷驾驶和独处旅行为核心的浏览器游戏。

> **当前阶段：需求与设计文档。** 已整理用户的体验偏好；目录中的技术骨架不代表游戏已经实现。先以文档对齐方向，再按里程碑开发。项目名、路线名称和世界布局均为暂定。

## 想要实现的体验

夕阳照进敞篷车的驾驶室，路边绿植随风晃动。沿着山海之间的公路慢慢前进，穿过隧道，出口处大海突然展开。可以自己开，也可以交给自动驾驶，切到电影镜头，听着音乐欣赏沿途小镇和海湾。

- 电脑浏览器与手机浏览器均可游玩。
- 三类敞篷车可切换：复古、现代豪华、运动。
- 三类视角：精细车内、可旋转第三人称、电影追随。
- 手动驾驶好上手，并有转向、惯性与刹车反馈；电影视角默认自动驾驶。
- 一个有岔路的小型自由探索区域，包含海岸公路、小镇、山路、隧道与观景点。
- 以开车穿行和欣赏风景为主，配合车载音乐、海浪、风声与发动机声。

## 开发原则

1. 先更新受影响的设计和验收项，再实现功能，保留可追溯的调整记录。
2. 先证明“驾驶一小段海岸已经有感觉”，再扩展整片地图。
3. 电脑与手机从第一段可玩场景共同验证，避免最后补触控。
4. 自动驾驶、细致车内视角和电影镜头属于核心需求。
5. 画面追求柔和电影感和丰富细节；《极限竞速：地平线 5》用于明确光影、风景、车辆与驾驶感的参考方向，最终规模和效果以浏览器实测为准。
6. 不把计划、截图或占位代码写成已完成的功能，不以构建通过代替游玩验证。
