# 逐海 · Golden Coast

一款以海岸风景、敞篷驾驶和独处旅行为核心的浏览器游戏。

> **当前阶段：M4 景观与自由探索迭代。** M76加入可选连续昼夜：暂停菜单开启“时间自然流动”，一昼夜约30分钟，天空、光照、阴影与海水一起变化，暂停时停留并保存当前时间；默认仍是固定18:42夕阳。代表时段、短程驾驶和浏览器检查已通过，正常速度完整一昼夜驾驶正在验证。四季和天气继续按文档11推进。一加12 Chrome本轮确认开启流动后“主画面和后视镜都顺畅”；完整热稳定和iPhone仍待验证。自然群落、陡坡路线可读性及部分渲染预算仍待改善。[本阶段证据](artifacts/final-evidence.md)。

手机卡顿定位：`npm run diagnose:phone` 启动独立5191检测页，`/?test=1`做静止对照；加`&drive=1`做四段实际巡航镜面开/关，再留10秒手动驾驶和转头。结果自动写入`artifacts/phone-probe-m70/reports/`，记录可信输入、帧间隔及稀疏驾驶状态。需保持前台。检测只测流畅档，不能代表其他画质、长时间发热或iPhone；不会替换正式`dist/`或5190入口，5191已占用时在构建前退出。

## 想要实现的体验

夕阳照进敞篷车的驾驶室，路边绿植随风晃动。沿着山海之间的公路慢慢前进，穿过隧道，出口处大海突然展开。可以自己开，也可以交给自动驾驶，切到电影镜头，听着音乐欣赏沿途小镇和海湾。

- 电脑浏览器与手机浏览器均可游玩。
- 三类敞篷车可切换：复古、现代豪华、运动。
- 三类视角：精细车内、可旋转第三人称、电影追随。
- 手动驾驶好上手，并有转向、惯性与刹车反馈；电影视角默认自动驾驶。
- 一个有岔路的小型自由探索区域，包含海岸公路、小镇、山路、隧道与观景点。
- 以开车穿行和欣赏风景为主，配合车载音乐、海浪、风声与发动机声。

## 开发原则

1. 先更新受影响的设计和验收项，再实现功能，保留可追溯的调整记录。
2. 先证明“驾驶一小段海岸已经有感觉”，再扩展整片地图。
3. 电脑与手机从第一段可玩场景共同验证，避免最后补触控。
4. 自动驾驶、细致车内视角和电影镜头属于核心需求。
5. 画面追求柔和电影感和丰富细节；《极限竞速：地平线 5》用于明确光影、风景、车辆与驾驶感的参考方向，最终规模和效果以浏览器实测为准。
6. 不把计划、截图或占位代码写成已完成的功能，不以构建通过代替游玩验证。

## 本地运行

```bash
npm ci
npm run dev -- --host 0.0.0.0
```

电脑访问 `http://localhost:5188/`。手机与电脑在同一局域网时使用终端输出的 Network 地址。验证命令：`npm run build`、`npm test`。测试使用已安装的 Chrome；当前开发环境在 Playwright 启动参数中启用硬件 GPU，避免软件渲染误导性能结果。

手机稳定试玩：与主机连接同一 Wi-Fi 后打开 [10.158.204.114:5190](http://10.158.204.114:5190/)；电脑本机打开 [localhost:5190](http://localhost:5190/)（2026-11-01已复核）。`npm run build` 后以 `npm run preview -- --host 0.0.0.0 --port 5190` 启动；主机换网时请使用终端输出的实际 Network 地址。点击开始自动尝试横屏全屏；手机默认流畅档，设置中可提高画质。暂停菜单可选择五个固定时段，或开启“时间自然流动”；关闭流动会停在当前时间，选择固定时段则退出循环。电脑H键或菜单控制车灯。一加12 Chrome已确认M76开启流动后主画面/后视镜顺畅；完整热稳定及iPhone仍待验证。本地试玩已更新，GitHub Pages并未随本轮提交更新。

## GitHub Pages 发布

在线游玩：[逐海 · Golden Coast](https://ryanhotan.github.io/coastline/)。Pages 使用 `gh-pages` 分支根目录中的构建产物。

本机具备 `origin` 仓库推送权限后，运行以下命令发布当前工作区：

```bash
npm ci
npm run deploy
```

`deploy` 先进行 TypeScript 检查，再以 `/coastline/` 为资源前缀构建并推送 `dist-pages/` 到 `gh-pages`。Pages 使用独立构建目录，避免被普通本地构建覆盖。它会包含本地尚未提交的源码改动所生成的页面，但不会提交或切换当前源码分支；源码提交和推送仍单独进行。GitHub 完成 Pages 发布后，线上页面更新。

只检查部署构建可运行 `npm run build:pages`，随后用 `npm run preview -- --base=/coastline/ --outDir=dist-pages` 预览，访问 `http://127.0.0.1:4188/coastline/`。普通 `npm run build` 和 `npm run dev` 继续使用根路径。
