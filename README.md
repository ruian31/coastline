# 逐海 · Golden Coast

一款以海岸风景、敞篷驾驶和独处旅行为核心的浏览器游戏。

> **当前阶段：M4 景观与车辆质感迭代。** 海岸、小镇、隧道、灯塔和支路已接入；三款车含驾驶者和可观察内饰，支持三视角、巡航、声音与触控。生产版本27项桌面/Android Chrome与WebKit行为测试、9项驾驶/音频/镜头与模型逻辑检查通过。用户实际评价风景50分、车辆70分、整体勉强60分；正重做侵蚀岩岸、扫描礁石和自然植被，随后继续车辆细节，持续目标仍进行中。项目名与路线名称暂定。

## 想要实现的体验

夕阳照进敞篷车的驾驶室，路边绿植随风晃动。沿着山海之间的公路慢慢前进，穿过隧道，出口处大海突然展开。可以自己开，也可以交给自动驾驶，切到电影镜头，听着音乐欣赏沿途小镇和海湾。

- 电脑浏览器与手机浏览器均可游玩。
- 三类敞篷车可切换：复古、现代豪华、运动。
- 三类视角：精细车内、可旋转第三人称、电影追随。
- 手动驾驶好上手，并有转向、惯性与刹车反馈；电影视角默认自动驾驶。
- 一个有岔路的小型自由探索区域，包含海岸公路、小镇、山路、隧道与观景点。
- 以开车穿行和欣赏风景为主，配合车载音乐、海浪、风声与发动机声。

## 开发原则

1. 先更新受影响的设计和验收项，再实现功能，保留可追溯的调整记录。
2. 先证明“驾驶一小段海岸已经有感觉”，再扩展整片地图。
3. 电脑与手机从第一段可玩场景共同验证，避免最后补触控。
4. 自动驾驶、细致车内视角和电影镜头属于核心需求。
5. 画面追求柔和电影感和丰富细节；《极限竞速：地平线 5》用于明确光影、风景、车辆与驾驶感的参考方向，最终规模和效果以浏览器实测为准。
6. 不把计划、截图或占位代码写成已完成的功能，不以构建通过代替游玩验证。

## 本地运行

```bash
npm ci
npm run dev -- --host 0.0.0.0
```

电脑访问 `http://localhost:5188/`。手机与电脑在同一局域网时使用终端输出的 Network 地址。验证命令：`npm run build`、`npm test`。测试使用已安装的 Chrome；当前开发环境在 Playwright 启动参数中启用硬件 GPU，避免软件渲染误导性能结果。

手机稳定试玩：同一Wi-Fi下打开 `http://192.168.3.10:5190/`（`npm run build` 后以 `npm run preview -- --host 0.0.0.0 --port 5190` 启动）。点击开始自动尝试横屏全屏；手机默认流畅档，设置中可提高画质。一加12 Chrome用户复测已确认明显更流畅与横屏全屏正常，iPhone真机仍待核验。
