| D10 | 电脑和手机浏览器都支持 | 用户补充手机浏览器要求 |

## 实现方提出、仍可调整的假设

| 编号 | 假设/提案 | 理由 |
| --- | --- | --- |
| P01 | 暂名“逐海 · Golden Coast” | 对应核心旅行感，便于工程命名 |
| P02 | 沿海主环线与一条相连内陆支路 | 用有限范围实现路线选择和海景节奏 |
| P03 | 固定落日时段作为第一版 | 优先做好用户描述中的关键光线 |
| P04 | 复古双座、现代豪华、轻型运动，使用虚构车型 | 让三车在轮廓、内饰和驾驶性格上有所区别 |
| P05 | 舒缓原创器乐、可调环境音 | 符合放松驾驶方向 |
| P06 | 轻量地标到访记录 | 帮助探索和定位，不增加任务压力 |
| P07 | 首版不包含下车步行 | 用户当前偏好以开车穿行为主，先完成核心体验 |
| P08 | 手机推荐横屏，竖屏保持可用 | 平衡风景构图和实际访问习惯 |
| P09 | 程序化资源为当前制作路线 | 外部资源生成服务均缺凭据，仍需实际画面验证质量 |
