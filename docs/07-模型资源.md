# 扫描模型资源

日期：2026-10-21。此文记录资源来源和集成策略；当前已接入关键路边近景，实际效果和性能需用游戏截图与诊断核验。

## Fern 02

来源：[Poly Haven · Fern 02](https://polyhaven.com/a/fern_02)，[CC0 许可](https://polyhaven.com/license)。作者：Rob Tuytel（扫描）、Rico Cilliers（建模）。下载时使用 `GoldenCoastAssetPipeline/0.1` User-Agent，原始 URL 与校验值保存在模型目录的 `source.json`。

- 浏览器入口：`public/assets/models/fern_02/fern_02_browser.gltf`。
- 四个独立蕨丛变体共 6,232 三角形，分别 2,384 / 2,248 / 784 / 816。
- 共享一个 PBR 材质，三张 1k 纹理。无骨骼与动画。
- 运行时外部引用共 1,675,520 字节：glTF、bin、RGBA 颜色、法线和 ARM。
- 模型以米为单位，每株约 0.55–0.99 米宽、0.21–0.43 米高。四株源节点按 2×2 展示排列；集成时应去掉展示位移，按各株根部放置。
- 原始 glTF 使用 MASK，但颜色 JPG 没有 Alpha，直接加载会让叶片间细缝不透明。本地版本将官方 Alpha PNG 无损合入官方颜色 RGB，恢复正确叶形；ARM 红通道接入 AO。模型几何未改变。
- 已用 GLTFLoader 检查引用完整性、边界、材质和透明叶片；结构结果见 `validation.json`。

集成策略：只在关键近景使用扫描蕨类，按材质实例化；远景继续用轻量植被。手机使用更少实例，复用四个几何变体，保持总场景预算，不以无限堆密度换取真实感。

## Coastal Cliff 01 评估

[Coastal Cliff 01](https://polyhaven.com/a/coastal_cliff_01) 的公开 glTF 虽标为可用 LOD，但各分辨率入口引用同一个约 13.18 MB 的几何 bin，实际约 461,824 三角形，未发现独立的低于 25k 三角形 glTF LOD。此次未下载该大几何，也未加入游戏；海崖继续采用经过设计的地形与扫描岩面材质。

评估结果位于 `artifacts/reference/fern-02/coastal_cliff_01-evaluation.json`，已将未使用评估、原始颜色/Alpha分离图、原始入口与预览移至开发证据目录，运行时只分发实际引用的模型与三张贴图。

## 实例与风动

四个变体各自实例化，桌面每种16株、手机每种4株；仅增加4次绘制，共用同一PBR材质与3张纹理。顶点风动固定根部、按世界位置产生相位差。平台与海湾休息处补充接地支柱和连接步道，避免悬空设施破坏真实感。
