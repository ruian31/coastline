## WebKit测试环境

主机Ubuntu26.04.1，Playwright WebKit26.4/build2287的Ubuntu24构建要求旧ABI库。只在 `work/webkit-runtime/` 下载官方Ubuntu `.deb` 并解压，通过局部启动器合并动态库路径；没有sudo、系统安装或配置变动。共约16.34MB包文件，完整来源与SHA256保留在该目录的manifest。

```bash
RUN_WEBKIT=1 \
PLAYWRIGHT_HOST_PLATFORM_OVERRIDE=ubuntu24.04-x64 \
PLAYWRIGHT_SKIP_VALIDATE_HOST_REQUIREMENTS=1 \
TEST_BASE_URL=http://127.0.0.1:4188 \
npx playwright test --project mobile-webkit
```

该环境为Linux WebKit引擎，并非iPhone。原始测试记录 `artifacts/webkit-compatibility.json` 显示completed=true、脚本错误/控制台错误/失败请求均0，包含声音解锁与暂停、触控、三镜头、选车和横竖屏操作。

Chrome开启ANGLE GL后实际使用NVIDIA RTX4050；WebKit桌面测试环境的低帧率不能用来推断iPhone性能。手机Chrome视口同样运行在桌面GPU上，不能当作Android真机性能证明。
